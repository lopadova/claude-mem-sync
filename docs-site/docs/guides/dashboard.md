# Dashboard

Run a local web dashboard for observations, search, analytics, access maps, profiles, team insights, and distilled knowledge.

```bash
mem-sync dashboard
mem-sync dashboard --port 8080
```

::: grids
::: grid
::: card "Overview" icon:layout-dashboard
Stats, project health, DB size, and merge cap progress.
:::
::: card "Observations" icon:list-filter
Search, filters, pagination, and detail views.
:::
::: card "Team Insights" icon:users
Concept coverage, survival rates, and bus-factor risk.
:::
:::
:::

::: callout warning "Local server"
The dashboard is for trusted local use. Do not expose it publicly.
:::
