# CLI Reference

| Command | Description |
| --- | --- |
| `mem-sync init` | interactive setup |
| `mem-sync config` | show configuration |
| `mem-sync setup-repo [name]` | scaffold shared repo |
| `mem-sync add-project` | add project |
| `mem-sync update-project` | update project config |
| `mem-sync preview` | dry-run export matching |
| `mem-sync export` | export filtered observations |
| `mem-sync import` | import merged observations |
| `mem-sync maintain` | backup, prune, optimize |
| `mem-sync status` | health check |
| `mem-sync schedule install` | install scheduled tasks |
| `mem-sync schedule remove` | remove scheduled tasks |
| `mem-sync ci-merge` | CI merge command |
| `mem-sync dashboard` | local web dashboard |
| `mem-sync profile` | generate profiles |
| `mem-sync distill` | generate distilled rules |

::: callout tip "Use --all carefully"
Commands with `--all` operate across every enabled project.
:::
